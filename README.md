# MamAlina Center

אתר בעברית עבור MamAlina Center בכפר סאלד: אימוני כוח בקבוצות בוטיק ונשימה וריברסינג עם אלינה, כולל תחום עצמאי לילדים ולתינוקות.

[האתר החי](https://www.mamalinacenter.co.il/)

## עדכון התוכן — 1 באוקטובר 2026

הנוסח העדכני מבוסס על `MamAlina_website_brief_HEBREW_RTL_FINAL.pdf` שנשלח על ידי אלינה. המסמך מחליף את הנוסח הקודם בפתיח, בשתי הכניסות לשירותים, באזור האישי, באזורי הכוח והנשימה, באזור הקשר ובפוטר. המבנה העיצובי נשמר: עברית RTL, גופנים מקומיים, שחור/לבן/בז׳, התמונות הקיימות, הסרטון וההמלצות האמיתיות.

הפתיח: ״הגוף מתחזק. הנשימה משחררת. החיים משתנים.״ משפט המותג: ״נשימה לחיים מאוזנים יותר.״ שני התחומים מוצגים כשני עולמות בתוך מרכז אחד.

אחרי אזור הנשימה מופיע אזור עצמאי לילדים ולתינוקות. הקישור ״קראו על ריברסינג לילדים ותינוקות״ פותח את המשך הטקסט בתוך העמוד באמצעות `details` נגיש שעובד גם ללא JavaScript. התמונה המומלצת של אמא וילד לא צורפה לבריף. עמוד נשימה מורחב הוזכר במסמך כהמלצה להמשך ולא נוצר כחלק מהעדכון.

## פיתוח מקומי

האתר סטטי, ללא התקנת חבילות או שלב build. להרצה מהתיקייה:

```sh
python -m http.server 4398 --bind 127.0.0.1
```

כתובת מקומית: `http://127.0.0.1:4398`.

## מבנה

- `index.html` — התוכן, הניווט וקישורי הקשר.
- `styles.css` — העיצוב, התאמה למסכים, RTL והעדפת תנועה מופחתת.
- `script.js` — תפריט נגיש, נגן וידאו, כפתור קשר במובייל, שליטה בתנועת הנשימה ואירועי מדידה.
- `assets/` — התמונות, סרטוני המקור והגופנים המקומיים, כולל רישיונות OFL.
- `PRODUCT.md`, `DESIGN.md`, `.impeccable/surfaces/index-html.md` — העובדות וההנחיות העדכניות להמשך עבודה.
- `.impeccable/alina-brief-review.md` — היקף השינוי ותוצאות הבדיקה.

## מסע העמוד והתנהגות

פתיח מותג ללא תמונה → שתי כניסות טקסטואליות שוות → אלינה ותמונת הלב → אימוני כוח, צילום האימון, הגישה והסרטון → המלצות אמיתיות → נשימה וריברסינג עם תמונת חדר אחת → ילדים ותינוקות → יצירת קשר.

קישורי WhatsApp נפתחים ישירות למספר העסקי, ללא הודעה מוכנה מראש. כפתורי הפעולה: ״לשיעור ניסיון״ בכוח, ״למפגש נשימה״ בנשימה ו״שלחו לי הודעה״ בקשר הכללי. אין טופס או מערכת הזמנות. המיקום מופיע באזור הקשר בלבד.

סרטון מרחב האימון באורך 24 שניות נטען רק לאחר לחיצה, ללא הפעלה אוטומטית, ונעצר ביציאה מהמסך. יתר הסרטונים ותמונות הסטודיו שמורים בקבצים ואינם מוצגים. ההמלצות הארוכות נגללות אופקית בטלפון. כפתור WhatsApp הצף מסתתר ליד בקרות ותוכן אינטראקטיבי, כולל פתיחת הפרטים לילדים ולתינוקות. התפריט והעדפת תנועה מופחתת נשמרים.

## פרסום ובדיקה

האתר מוגש באמצעות GitHub Pages מתוך `main`. מצב הפרסום זמין ב־Actions של המאגר אחרי דחיפה.

Google Analytics 4 מחובר באמצעות `G-S5KM730ENY`. אירועים: `contact_click` עבור WhatsApp/טלפון/אינסטגרם, `service_interest` עבור בחירת שירות ופתיחת פרטי הילדים (`children_breath`), ו־`video_start`/`video_complete` עבור הסרטון. Google Signals ואותות להתאמה אישית של פרסום מושבתים בקוד.

בדיקות העדכון כיסו רוחבי 320, 390, 430, 768 ו־1440 פיקסלים, התאמה של מלל האתר למלל שחולץ מה־PDF, היעדר גלישה אופקית וקישורים שבורים, מקלדת ותפריט, פתיחת פרטי הילדים, הסרטון, העדפת תנועה מופחתת ובדיקות נגישות של התוכן הראשי במחשב ובטלפון. תוצרי הבדיקה המקומיים נשמרים ב־`.qa/`, שאינה נכללת ב־Git.
