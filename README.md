# MamAlina Center

אתר בעברית עבור MamAlina Center בכפר סאלד: אימוני כוח וקליניקה נפרדת לנשימה עם אלינה. עיצוב Signature אושר ב־7 בספטמבר 2026.

[האתר החי](https://rluzzatt.github.io/AlinaFitnes/)

## פיתוח מקומי

האתר סטטי, ללא התקנת חבילות או שלב build. אפשר לפתוח את `index.html` בדפדפן, או להריץ מהתיקייה:

```sh
python -m http.server 4398 --bind 127.0.0.1
```

ואז לפתוח את `http://127.0.0.1:4398`.

## מבנה

- `index.html` — התוכן, הניווט וקישורי הקשר.
- `styles.css` — העיצוב והתאמה למסכים, RTL והעדפת תנועה מופחתת.
- `script.js` — תפריט נגיש, מעבר בין מצבי כוח ונשימה בפתיח, נגן וידאו, כפתור קשר במובייל ושליטה בתנועת הנשימה.
- `assets/` — התמונות וסרטוני המקור המקומיים.
- `assets/fonts/` — גופני Anton ו־Noto Sans Hebrew מקומיים, כולל רישיונות OFL.
- `assets/images/*-retouched.webp` — תמונות החללים לאחר ניקוי רצפות ופרטים ושיפור תאורה ב־AI. תמונת הלב הראשית היא `alina-portrait-editorial.webp`; קובצי המקור והעריכות הקודמות נשמרו.
- `.impeccable/` — הכיוון שאושר, סקיצות, מקורות השראה ומפרט העמוד.
- `DESIGN.md` — הנחיות להמשך עבודה על העיצוב.

קישורי WhatsApp נפתחים ישירות למספר העסקי, ללא הודעה מוכנה מראש. התוכן, שני השירותים, סרטון מרחב האימון ודרכי הקשר זמינים גם ללא JavaScript. סרטון מרחב האימון נטען רק לאחר לחיצה; אין הפעלה אוטומטית. הסרטונים ״רגע מתוך האימון״ ו״הציוד בסטודיו״ הוסרו מהעמוד. התמונות והגופנים מוגשים מהמאגר, ללא תלות בשירות חיצוני בזמן טעינת האתר. התמונות המשופרות נשמרות כ־WebP לצד קובצי המקור. תמונת הלב פותחת את האתר. ההקדמה מבהירה שאפשר לבחור אימוני כוח או מפגשי נשימה בנפרד, ושם העסק מופיע מתחת ללוגו הגדול. בורר השירותים נמצא מיד מתחת לכותרת האתר. כל בחירה מציגה צילום נפרד ותוכן שמתאים לשירות, ללא חיתוכים אלכסוניים או טקסט שמכסה את התמונה.

## פרסום ובדיקה

האתר מוגש באמצעות GitHub Pages. דוח הבנייה והפרסום זמין ב־Actions של המאגר לאחר דחיפה ל־`main`.

לפני פרסום, יש לבדוק את התצוגה במחשב ובטלפון, את התפריט באמצעות מקלדת, את הקישורים ואת מצב התנועה המופחתת. תיקיית `.qa/` מיועדת לתוצרי בדיקה מקומיים ואינה נכללת ב־Git.
